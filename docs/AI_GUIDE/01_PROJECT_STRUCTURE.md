# 01. Project Structure and Setup

## 🚨 UI FRAMEWORK NOTICE

**This project uses React Bootstrap as the primary UI framework.**

The dependency installation commands in this document show Radix UI packages, but the actual project uses:
- **React Bootstrap** - Primary UI components
- **react-icons/fa** - Icons
- **SweetAlert2** - Alerts
- **react-number-format** - Currency inputs

See [00A_UI_UX_REFERENCE.md](./00A_UI_UX_REFERENCE.md) for the correct UI patterns.

## 🚀 Project Initialization

### Step 1: Create Next.js Project

```bash
# Create new Next.js project with TypeScript and Tailwind
npx create-next-app@latest finance-app --typescript --tailwind --app --src-dir --import-alias "@/*"

# Navigate to project
cd finance-app
```
